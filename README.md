# 🍽️ Restaurant Orders SQL Analysis

## 📌 Project Overview

This project analyzes restaurant order data using **MySQL** to explore menu items, ordering patterns, customer spending, and restaurant sales.

The analysis uses two relational tables:

* `order_details` — contains information about orders and ordered items
* `menu_items` — contains information about menu items, categories, and prices

I used SQL to combine these tables and answer practical, business-oriented questions about the restaurant's orders and menu.

The main objectives of this project were to:

* Explore the restaurant's order data

## 🗂️ Database Structure

The project contains two main tables.

### `order_details`

Stores information about individual items included in each order.

| Column             | Description                     |
| ------------------ | ------------------------------- |
| `order_details_id` | Unique ID for each order detail |
| `order_id`         | ID of the order                 |
| `order_date`       | Date the order was placed       |
| `order_time`       | Time the order was placed       |
| `item_id`          | ID of the menu item             |

### `menu_items`

Stores information about the restaurant's menu.

| Column         | Description                |
| -------------- | -------------------------- |
| `menu_item_id` | Unique ID of the menu item |
| `item_name`    | Name of the menu item      |
| `category`     | Category of the menu item  |
| `price`        | Price of the menu item     |

### Relationship

The tables are connected through:

```text
order_details.item_id
        ↓
menu_items.menu_item_id
```

This relationship allows order information to be combined with menu information for analysis.

# 🔍 Analysis Performed

## 1️⃣ Order Analysis

The order data was analyzed to answer questions such as:

* What is the date range of the available orders?
* How many unique orders were placed?
* How many items were ordered?
* Which orders contained the most items?
* How many orders contained more than 12 items?

---

## 2️⃣ Menu Analysis

The menu data was analyzed to understand:

* Total number of menu items
* Least expensive menu item
* Most expensive menu item
* Number of Italian dishes
* Least expensive Italian dish
* Most expensive Italian dish
* Number of dishes in each category
* Average price of dishes in each category

---

## 3️⃣ Combined Order & Menu Analysis

The `order_details` and `menu_items` tables were joined using `LEFT JOIN` to perform deeper analysis.

The combined analysis explored:

* Most frequently ordered menu items
* Least frequently ordered menu items
* Top 5 highest-spending orders
* Revenue generated by each menu category
* Number of items ordered by category
* Category breakdown of high-spending orders

# 📊 Key Business Questions

Some of the main questions explored in this project include:

### Menu

**Which menu items were ordered most frequently?**

This helps identify popular dishes.

### Pricing

**What is the average price of dishes in each category?**

This helps compare pricing across different menu categories.

### Orders

**Which orders had the highest total spending?**

This helps identify high-value orders.

### Revenue

**Which menu categories generated the most revenue?**

This provides a category-level view of restaurant sales.
